## Coded Clay

**Coded Clay** is a series of 3D printed clay vessels generated from mathematical formulas. Each piece starts as an equation — written in Python inside Blender, drawing on Joseph Choma's book *Morphing* — and ends as a physical object, printed on a CNC machine I adapted for clay extrusion.

![Parametric Clay Design](/assets/images/vase3.png)

### The Process

I design seamless surfaces whose texture comes directly from the layering of the print itself. Because every object is generated from a formula, changing a few parameters produces a new variation — the same code can output an endless family of related pieces, each one printable and each one different.

![3D Printed Clay Process](/assets/images/vase2.jpg)

![Intricate Clay Cup Design](/assets/images/vase002.png)

### Espresso Cups

The same workflow, scaled down to everyday objects. These espresso cups are modeled with Sverchok: a watertight toolpath for the base, then a spiralized contour that builds the cup as one continuous line of clay from bottom to rim. Small changes in the texturing parameters give every cup its own fingerprint.

![Parametric Clay Espresso Cup](/assets/images/cup.jpg)

![Array of 3D Printed Espresso Cups](/assets/images/tasas.jpg)

### Code Meets Craft

The tools here are code and machines, but the result is still pottery. That is what interests me about this project: digital fabrication doesn't replace traditional craft — it gives it another set of hands.
